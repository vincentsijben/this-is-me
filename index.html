Waarom D3?

Waarom behandelen we juist webscripting? Je kunt data snel bewerken alvorens je het eindwerk wellicht afmaakt met de hand Het is interactief (een gebruiker kan klikken je kunt dus meer informatie compacter weergeven) Het is online beschikbaar, dus makkelijk deelbaar Je kunt web API’s gebruiken, zodat je project realtime met dynamische data werkt D3 is een library in javascript waarmee we heel snel SVG’s kunnen maken die data driven zijn, animeren én interactief zijn We leren echt de basics. Het is aan jezelf om te exploreren en de écht vette dingen te maken.

Eindopdracht is interactief

In samenspraak met je coaches tik je af wat je gaat maken. Zonder techniek wordt het lastig iets interactiefs te maken, bijvoorbeeld een online webpage waar de klant zelf aan de knoppen kan draaien. De beschrijving van het eindwerk is beschreven in Moodle. Je bent niet verplicht D3 te gebruiken in je eindwerk, maar als het goed is zie je wel het nut ervan in om te kunnen prototypen of om een interactieve website te kunnen maken. Het mag ook met andere technieken, maar overleg dat vooral met mij. PowerBI is bijvoorbeeld niet de bedoeling. Een interactieve website is dan dus én deelbaar én heel bruikbaar voor de klant.

MMT2 opdracht 1

"Geef me de oplossing voor een opdracht in P5js. Toon 8 vierkanten. 4 boven, 4 beneden. In de bovenste rij heeft ieder vierkant een andere felle kleur en geen rand, in de onderste rij een grijstint van wit (links) tot zwart (rechts) met een rand."

  • Probleem: je moet super expliciet zijn, anders kloppen de kleuren en layout niet
  • Oplossing: "... de vierkanten moeten 50x50 pixels worden en de ruimte om iedere pixel is ook 50pixels. Geef het canvas een grijze achtergrond."
  • Probleem: opeens andere kleuren en de oplossing bevat concepten die we nog niet behandeld hebben (arrays en loops).
  • Oplossing: "... pas de code aan zodat geen arrays of loops worden gebruikt."

Maar wat hebben we nu geleerd?

  1. Je leert enkel goed de opdracht omschrijven, je leert niet hoe je het zelf moet oplossen.
  2. Je leert niet hoe je de code moet schrijven.
  3. Je leert niet hoe je de code moet debuggen.

Wat wil ik dan wel?

"... Geef me niet de complete oplossing. Zorg ervoor dat ik het zelf kan oplossen."

"... Leg het uit alsof ik 10 ben."

"Help me stap voor stap het concept van gekleurde vierkanten in p5js te begrijpen. Geef me een instructie, laat me de code schrijven, controleer mijn antwoord en ga pas door naar de volgende stap als het goed is. Geef zelf geen complete antwoorden."
